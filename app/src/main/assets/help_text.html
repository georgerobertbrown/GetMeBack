Tips and suggestions

General

The main action buttons are located in the bottom right of the screen. Long-press on a button for a pop-up description of the button action. General application buttons are located across the top:
  • Tap the Settings icon to update various application settings, e.g. GPS update interval, minimum update distance and interval.
  • Tap the Close icon to close the application.
  • Tap the More icon to show a menu for additional capabilities.
When dealing with Android's location service, getting the current location or the address from the location can take some time. You may notice a delay in acquisition until the operation is complete.

Getting location

Tap the pushpin icon to get the current location. The location request will be processed in background. When the location is acquired, a separate background task will be started to get the address (located below the icons). The address will be updated automatically.

Returning to the destination

  • Tap the map icon to request Google turn-by-turn directions. A dialog will appear requesting the navigation method: driving, walking, bicycle, transit.
  • Tap the map icon to request Google precise navigation. A dialog will appear reminding you that this is a battery-intensive operation.
NOTE:
  • it may take some time to get the current location and navigation directions
  • if the current location and destination are too close together, it may result in a Google navigation error

    • Setting destination address

    Tap the address text field to enter a new address. The keyboard on WearOS devices are tiny so be patient. Tap the check mark to enter the new address. The location will be acquired from the address.

    Home screen widget

    A Home screen widget can be created to quickly set the current location and return to the destination. Steps:
    1. long-press on the Home screen
    2. select Widgets
    3. tap GetMeBack!
    4. press and hold the widget preview icon
    5. drag the widget to the Home screen

    Set destination

    Tap the icon to set your current location as destination location. This will be the location GetMeBack will return to when the Return to destination button is selected.

    Return to destination

    • Tap the icon to launch Google's turn-by-turn navigation. It will prompt for the navigation mode, either driving, walking, bicycle, or transit.
    • Tap the icon to launch Google's precise location navigation.

    Main screen

    Tapping on the main screen will prompt to set that as the new destination. It will display the geolocation and the street address. Tap OK to set as the new destination or Cancel.

    Named locations

    Locations can be assigned a name and restored for future use. For example, you can have a location named Home, Work, Gym, etc. Named locations options are available under the More menu.
    1. Save location Pops up a dialog to enter the location name.
    2. Restore location Select one of the named locations to set as the current location.
    3. Forget location Removed the location name.

    Settings

    Various settings are available under the Settings menu. They are grouped under the following categories:

    GPS Settings

    • GPS update interval: Sets the desired interval of location updates.
    • Min update distance: Sets the minimum distance required between consecutive location updates.
      If a derived location update is not at least the specified distance away from the previous location update delivered to the client, it will not be delivered. This may also allow additional power savings under some circumstances.
    • Min update interval: Sets the fastest allowed interval of location updates.
      Location updates may arrive faster than the desired interval (setIntervalMillis(long)), but will never arrive faster than specified here.
    • Max update delay: Sets the longest a location update may be delayed.
      This parameter controls location batching behavior. If this is set to a value at least 2x larger than the interval specified by setIntervalMillis(long), then a device may (but is not required to) save power by delivering locations in batches.
      If clients do not require immediate delivery, consider setting this value as high as is reasonable to allow for additional power savings. When the LocationRequest is built, the maximum update delay will be set to the max of the provided maximum update delay and the interval. This normalizes requests without batching to have the maximum update delay equal to the interval.
      For example, if a request is made with a 2s interval and a 10s maximum update delay, this implies that the device may choose to deliver batches of 5 locations every 10s (where each location in a batch represents a point in time ~2s after the previous).

    Map Settings

    • Show buildings: Turns the 3D buildings layer on or off.
    • Show traffic: Turns the traffic layer on or off.
    • Indoor mode: Sets whether indoor maps should be enabled.
      Currently, indoor maps can only be shown on one map at a time and by default, this is the first map added to your application.
      To enable indoor maps on another map, you must first disable indoor maps on the original map. If you try to enable indoor maps when it is enabled on another map, nothing will happen and this will return false. When Indoor is not enabled for a map, all methods related to indoor will return null, or false.

    Miscellaneous Settings

    • Kill precise navigation after: Kills the precise navigation after the specified time. This preserves battery in the case you left precise navigation running.
    • Tone on location update: Plays a tone on GPS hits. A debugging tool to let you know that your are receiving GPS updates.
    • Debug mode: Enable/disable additional debugging information
    RESET SETTINGS button: resets settings to their default.
